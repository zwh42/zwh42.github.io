# 端点星日志重构

参考 https://s1.work/categories/ 的暖黑与橙色、窄栏、等宽排版、分类卡片、标签与时间线。首页使用最新文章及单列列表；所有模板共享导航、阅读进度、主题和页脚，保留文章 URL、搜索、RSS 与移动端阅读。

分类和标签在 Liquid 构建时从文章元数据提取。显式 categories/tags 优先；缺失分类按标题和标签匹配 `_data/taxonomy.yml`，没有匹配时归入随笔；缺失标签按标题和摘要的关键词规则提取。索引及数量由文章实时汇总，不需要自定义插件，兼容 GitHub Pages 原生构建。已有标签名称保持不变。

验证生产构建、所有分类/标签计数与归属、文章链接与图片、旧路由、空结果、无标签的新文章、显式分类、搜索、主题、窄屏溢出及键盘访问。
