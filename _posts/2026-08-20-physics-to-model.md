*2026-10-25 修订 · [计算光刻阅读路线](/lithography/)*

计算光刻模型把晶圆目标与掩模、照明及工艺参数连接起来。设计目标经过目标调整和 OPC 或 ILT 形成掩模图形，实际掩模经曝光、显影和刻蚀形成晶圆轮廓。显影后检查（ADI）与刻蚀后检查（AEI）对应不同的输出平面，前向模型需要保留预测该平面所需的光学、材料和几何状态。

在给定掩模、照明、扫描机、光刻胶、刻蚀及工艺条件时，前向问题可写为

$$ C_{\mathrm{wafer}}=\mathcal F(M,S,\mathrm{scanner},\mathrm{resist},\mathrm{etch};\mathbf c). $$

反问题则在设备和制造约束内选择光源、目标偏置及掩模，使多种图形在焦点位置、剂量等过程变化下满足规格。模型开发由此包含目标定义、实验设计、参数辨识、紧凑表示、独立验证与版本管理；拟合系数只是其中一项产物。

本文依据 imec、Intel、TSMC、GlobalFoundries、IBM 以及设备和 EDA 厂商公开的论文、专利与技术资料，分析数据如何约束模型。公开案例中的实验条件及数值仅适用于相应研究范围，完整的先进工艺基准流程并未公开。

## 目标平面与误差预算

模型开发的第一项工作，是确认模型准备预测哪一个平面。CD 数据采集要服从这个目标。

只做光刻校正时，输出通常是 ADI 轮廓。面向最终图形的刻蚀感知 OPC 则要预测 AEI 轮廓。接触孔、线端或多层交叠结构还可能需要把局部面积、图形位置或套刻后的有效重叠写进目标。目标平面不同，实验数据、模型结构和验收指标都会跟着变化。

团队随后分配 EPE 预算。掩模写入、扫描机、光刻胶、刻蚀、套刻、计量和 OPC 残差各自可以占用多少误差，需要在模型建立前明确。这个预算决定哪些效应必须单独建模，哪些可以作为受控波动，哪些只能留给工艺控制。若刻蚀已经占去大部分图形相关偏差，继续增加光学模型的复杂度对最终 AEI 精度的改善有限。

模型边界确定以后，初始信息可以分成四层。

| 数据层 | 典型内容 |
| --- | --- |
| 工艺与设备设定 | 波长、NA、剂量、焦点位置、照明设定、胶厚、PEB、膜层、刻蚀配方 |
| 独立物理量测 | 光源分布、像差、flare、偏振、掩模 CD、膜厚、材料 n 和 k |
| 晶圆响应 | ADI CD、SEM 轮廓、Bossung、FEM、缺陷、AEI CD、AEI 轮廓、截面剖面 |
| 拟合所得参数 | 有效阈值、扩散长度、负载核、刻蚀核、计量校正 |

获取方式和风险也要分开记录。

| 数据层 | 获取方式与主要风险 |
| --- | --- |
| 工艺与设备设定 | 来自设备配方、材料记录和工艺记录。设定值可能偏离晶圆实际经历值 |
| 独立物理量测 | 来自扫描机传感器、AIMS、掩模 SEM、散射测量和膜厚量测。量测误差可能被后级经验参数吸收 |
| 晶圆响应 | 来自曝光分组实验、CD-SEM、电子束检测、XSEM 和 AFM。主要风险包括采样偏差、SEM 收缩、充电效应和图形匹配错误 |
| 拟合所得参数 | 来自模型校准和残差分析。参数可能互相补偿，造成训练误差很小而外推失效 |

前两层定义制造系统的物理输入，第三层记录晶圆响应，第四层由这些输入和响应估计得到。数据来源和不确定度需要分别记录，以区分输入偏差、观测误差和参数补偿。

波长、NA、光源形状和物镜像差能够独立量测时，应尽量把它们作为光学模型的物理输入。胶的扩散长度或经验阈值很难直接从量产胶中完整分离，通常要由晶圆 CD 和轮廓拟合。刻蚀的局部负载效应更复杂，往往只能压缩成少量核函数或规则表。

模型失配时，分层结构用于定位误差来源。需要依次检查光源漂移、掩模 CD、胶厚或 PEB、CD-SEM 配方及紧凑模型的图形覆盖。若将这些效应全部交由灵活的光刻胶模型项吸收，较低的训练误差可能掩盖输入偏差和模型形式误差。

可独立量测的物理量应优先作为固定输入，难以直接量测的效应再由校准约束。这样有助于减少参数补偿，保留光源、掩模或工艺条件改变时的预测能力。

## 跨工艺环节的数据与职责

在晶圆厂里，模型开发很少由一个 OPC 工程师独立完成。不同团队掌握不同的物理对象，也对不同的发布风险负责。

| 角色 | 主要工作与交付数据 |
| --- | --- |
| 光刻工艺工程师 | 定扫描机、光刻胶、涂胶显影设备、PEB、显影和工艺窗口<br>数据<br>POR 条件、FEM 晶圆、ADI CD、缺陷与剖面 |
| 扫描机和应用工程师 | 建照明、量光瞳、像差、焦点位置、剂量与机台匹配<br>数据<br>实测光源、物镜响应特征、扫描机限值和监控数据 |
| 掩模工程师 | 做测试掩模、量掩模 CD、角部圆化、吸收体与写入误差<br>数据<br>实测掩模几何、掩模堆栈、MRC 与掩模波动 |
| 计量工程师 | 定 CD-SEM 配方、轮廓提取、重复量测与机台匹配<br>数据<br>CD、轮廓、不确定度、收缩与充电效应评估 |
| OPC 建模工程师 | 设计采样方案、拟合子模型、分析残差、维护配方<br>数据<br>校准、验证、模型包、覆盖报告 |
| 刻蚀工程师 | 定刻蚀 POR、做工艺分组、量 AEI 与剖面<br>数据<br>ADI 和 AEI 配对数据、刻蚀偏差、负载与腔体信息 |
| 工艺集成、器件和良率工程师 | 定最终晶圆目标，确认跨层、电性和良率结果<br>数据<br>目标、EPE 预算、产品热点、缺陷与电性结果 |

OPC 开发周期还受到物理实验与数据准备的限制。测试掩模要先写出，扫描机和涂胶显影设备要有稳定条件，晶圆要排进实验，CD-SEM 配方要调好，刻蚀后还要找到与 ADI 对应的图形。任一环节的样本编号、条件或坐标管理出错，拟合工具仍可能给出一组参数，只是这组参数已经失去物理意义。

模型数据需要完整的追溯记录。每个量测结构或轮廓至少应能追溯到设计目标、掩模位置、晶圆、批次、曝光场、芯片、焦点位置、剂量、工艺步骤、计量配方和图像。被删除的异常值也要保留原因。否则下一轮晶圆结果变化时，团队无法判断过程变了，量测变了，还是数据处理变了。

## 照明方案的优化与设备实现

### 代表图形与照明目标

这里的光源通常指照明光瞳上的强度分布，而非光源功率本身。

光源的候选方案来自待印图形和工艺目标。工程师会准备一组有代表性的局部图形或量测结构，覆盖关键节距、密集和孤立图形、线端、端到端、拐角、接触孔、SRAM 以及历史热点。SMO 工具改变光瞳中各位置的照明强度，同时调整主图形或 SRAF，并在多个评价量之间求折中。

常见评价量包括共同焦深、曝光裕量、NILS、MEEF、EPE、工艺变化带，以及掩模复杂度和掩模规则约束。目标不会只是标称条件下的一次完美成像。光源要让多种图形在同一剂量和焦点位置范围内同时可制造，还要能被真实照明器实现。

这里用到的是代表性采样与稳健优化。版图空间远大于 SMO 能一次处理的局部图形数量，工程师先让样本集合覆盖主要成像行为，再优化最差图形、平均表现和硬件约束之间的折中。若优化集只包含密集线条，算法很可能牺牲孤立和二维端点。若只追求最佳焦点下的 EPE，所得光源也可能没有可用的工艺窗口。

imec 在 2024 年公开的一项 High-NA EUV 研究，从一平方微米的随机逻辑金属层单元中选取 200 个量测结构，覆盖密集、孤立和端到端图形，再比较亮场、暗场、不同吸收体与有无 SRAF 的组合。[[1]](https://doi.org/10.1117/12.3010869) 这类图形选择很重要。选择过少，光源会偏爱少量测试图形。选择过多而不做覆盖分析，计算成本和数据冗余又会迅速上升。

GlobalFoundries 与 ASML Brion 公开过更接近量产导入的 ArF SMO 案例。第一组包含 112 个关键 SRAM、测试图形和热点，用于光源优化。第二组超过 500 个局部图形，用于独立验证，另有较大器件结构参与检查。[[2]](https://doi.org/10.1117/12.916614) 这个做法揭示了一条基本原则，参与优化的图形和验证光源泛化能力的图形应当分开。

### 目标、设定与实测光源

光源进入晶圆厂后，会先后出现三种形态。

第一种是 SMO 工具给出的目标光源。它可能是连续强度分布，也可能具有很细的自由形状。

第二种是曝光机能够加载的设备设定光源。连续光源需要经过光源映射，还要满足照明器的最小光瞳填充、模糊、强度分辨率和硬件可实现性。

第三种是曝光机里实际形成的实测光源。它由扫描机的光瞳传感器或相应量测方法得到，包含实际光学系统的偏差。

仿真代表实际曝光的前提，是目标、设备设定和实测光源之间的偏差得到量化并受控。Huang 等人的 FlexRay 实验先用 Tachyon 做完整 SMO 和单独光源优化，再把光源加载到 ASML XT 1950i。曝光前后，研究者使用扫描机内置传感器收集光瞳信息，比较实际光源、设备设定光源和模拟 CD，随后跑 FEM 与关键缺陷扫描。[[3]](https://doi.org/10.1117/12.879567)

Nikon、Huali 与 Mentor 的联合研究也把实测光源分布与 SMO 光源做相关性验证，并用 FEM 晶圆检查仿真和晶圆工艺窗口。[[4]](https://doi.org/10.1117/12.2223576) 这说明光源优化完成只是中间节点。将光源渲染、写入扫描机、量出实际光瞳，再看晶圆响应，才完成一次实物验证。

### 光源变化与模型适用域

光源决定了哪些衍射级进入投影物镜，也改变空中像、NILS、跨节距行为和焦点位置敏感度。原模型里的光刻胶模型项即使能够勉强吸收部分变化，也容易损害外推能力。

GlobalFoundries 的公开流程在优化光源安装后，重新收集标称条件、离焦和非标称剂量的晶圆 CD，校准新的掩模 3D 模型，调新的 OPC 校正流程，制作新掩模版，再做晶圆验证。[[2]](https://doi.org/10.1117/12.916614) 这个顺序很有代表性。

因此，只用一张光瞳图片无法描述 SMO 的完整产物。实际交付还包括彼此匹配的光源规格、扫描机设定、OPC 模型、OPC 校正流程、SRAF 策略、MRC 与验证条件。

## 实验设计与效应分离

有了候选光源和初步工艺，下一步是设计能辨识工艺响应的测试载体。

测试载体的方法论目标可以用一个词概括，辨识力。一个待估参数发生变化时，量测数据中应当出现能够和其他参数区分的签名。密集到孤立的节距扫描用来观察邻近响应，焦点位置和剂量分组实验用来观察 Bossung 斜率，掩模偏置分组帮助区分掩模响应，ADI 与 AEI 配对则把光刻和刻蚀分开。只收标称条件 CD，许多参数会给出几乎相同的拟合结果。

最基本的一维图形包括密集到孤立的线空图形、不同目标 CD、不同节距、线条和间隔两种图形极性、有无 SRAF、不同掩模偏置。二维图形包括线端、拐角、折角、T 形交叉、端到端、端到线、接触孔或通孔阵列、二维孤岛图形，以及 SRAM 和真实产品热点。

规则图形便于控制单个变量，分离跨节距、剂量和焦点响应；二维与产品图形则覆盖规则阵列之外的圆角、端点回缩、相邻边耦合和 SRAF 交互。两类样本分别提供效应辨识和实际邻域覆盖。

测试掩模还要故意放进一些边界样本。它们可能接近光刻胶倒塌、桥连、残胶、接触孔缺失或掩模规则限值。边界样本不一定适合承担主拟合，却很适合检验模型能否识别失效起点。这类尺寸和间距经过特意安排、接近临界成像的定制图形，可以在模型建成后承担额外验证。稳定的模型既要把正常图形的平均 CD 拟合准确，也要预测这些图形何时开始失效。

Keck 等人公开的模块化建模实例使用 1560 个 CD 量测，覆盖四种工艺条件。约 85% 是一维图形，约 15% 是二维图形，内容包括带或不带 SRAF 的线空图形、孤立图形和线端。[[5]](https://doi.org/10.1117/12.716295) Weisbuch 等人在 28 nm 有源区工艺层的生产导入中，又比较了传统量测结构与 SEM 轮廓。轮廓能在一个二维结构中产生大量 EPE 点，提高局部边缘覆盖。[[6]](https://doi.org/10.1117/12.2048288)

到了更先进的节点，测试载体还要有意识地覆盖真实产品的图像参数空间。只按几何宽度和间隔取样可能漏掉光学上完全不同的二维邻域。IBM 的自动采样方案研究尝试从候选图形中挑选更少但更有代表性的样本。[[7]](https://doi.org/10.1117/12.2086049)

采样方案也受量测时间约束。一块测试掩模可以放很多图形，CD-SEM 却要逐个寻址、自动对焦、识别图形、采图和量边缘。规则 CD 量测结构较快，二维轮廓和大视场图像提供的信息更多，采集和处理成本也更高。工程师会把少量高信息量轮廓与较大规模的 CD 量测结构混合使用，并给关键图形安排重复芯片，以区分系统误差和随机变化。

采样方案需要同时覆盖产品图形、提供参数敏感的工艺分组、通过重复量测估计噪声，并预留独立验证样本。大量重复的量测结构主要降低噪声；具有不同敏感度方向的二维轮廓才可能增加参数辨识能力。

### imec 的量测实验

imec、Applied Materials 和 Siemens 在 2024 年公开了一套很具体的 EUV 实验。[[8]](https://doi.org/10.1117/12.3010898)

他们使用 imec iN3 BEOL 设计、EUV CAR 和 PTD，以及经过 SMO 的曲线测试掩模。实验一共用了四片晶圆。

| 晶圆用途 | 数据目的 |
| --- | --- |
| 光刻标称条件晶圆 | 找 ADI 标称条件响应，也用于比较 CD-SEM 扫描条件 |
| 光刻 FEM 晶圆 | 收集焦点位置和剂量变化下的 ADI 数据 |
| 刻蚀标称条件晶圆 | 得到标称条件 AEI 与刻蚀偏差 |
| 刻蚀工艺窗口晶圆 | 检查工艺波动下的刻蚀响应 |

公开数据里，标称条件晶圆选择了 50 个一维图形，FEM 晶圆选择了 42 个二维位置。量测对不同着陆能量和重复次数做了安排。光源优化时使用了焦点位置从负 30 nm 到正 30 nm、15 nm 步长，剂量从正 5% 到负 5%、2.5% 步长，并加入全局掩模偏置分组。

光源安装并曝光以后，团队才确定最终 OPC 模型采样方案。测试掩模上的一维线空图形从 32 nm 节距延伸到 320 nm 孤立节距，二维部分来自多个节距的 OPC 后的后段互连设计。最终用于校准的数据约为 700 个量测结构加 15 个轮廓，用于验证的数据约为 1400 个量测结构加 42 个轮廓。[[8]](https://doi.org/10.1117/12.3010898)

这些数字不宜复制成任何工厂的标准模板。它们说明了数据计划的结构。标称条件与工艺窗口分开，一维与二维并存，校准与验证分开，ADI 与 AEI 分开，同时保留重复量测来观察随机变化和量测误差。

### 焦点—剂量矩阵与响应斜率

FEM 是焦点—曝光矩阵。晶圆上的不同曝光场或芯片使用不同焦点位置和剂量组合曝光，显影后量 CD、EPE、轮廓和缺陷，就能得到 Bossung 曲线与工艺窗口。

在一维图形上，Bossung 曲线能显示 CD 随焦点位置的变化，以及不同剂量下曲线的平移。对多个节距和图形类型同时采样，模型就能学习密集和孤立图形的最佳焦点差异、跨节距偏差、剂量敏感度和焦点位置敏感度。

标称条件数据适合锁定最佳条件下的图形误差。非标称焦点与剂量数据用于约束模型的斜率和工艺窗口行为。若模型只在标称条件校准，可能在中心点非常准确，离开中心点后迅速失真。工艺窗口 OPC 和验证因而需要连续或多条件模型。[[9]](https://doi.org/10.1145/1146909.1147108)

标称条件 CD 约束局部响应的截距，焦点和剂量分组实验约束导数，跨节距图形约束邻域响应，重复芯片估计随机误差。每组实验应对应明确的待区分机制。

数据也不必全部进入拟合。比较稳健的做法是提前划出校准集和验证集。验证集应包含未参加拟合的节距、二维环境或工艺条件。它检验的内容比总体 RMS 更重要，包括系统残差是否随节距、CD、方向、焦点位置、剂量、掩模偏置或图形类别变化。

Klostermann 等人的物理光刻胶模型研究使用数千个 CD 和多达 30 个 FEM，并明确区分训练与验证。他们还发现，使用实测光源形状与标称条件光源形状会得到不同的模型质量。[[10]](https://doi.org/10.1117/12.814216) 这再次表明，晶圆数据和扫描机响应特征必须相互对应。

## 分层校准与全芯片应用

### 独立量测与待拟合参数

Mack 对 OPC 校准的总结列出了一批能够独立量测的输入，包括波长、NA、物镜像差、光源形状、光刻胶厚度、吸收与掩模线宽。[[11]](https://doi.org/10.1117/12.728961) 先进模型还会加入偏振、flare、掩模吸收体 n 和 k、掩模厚度、晶圆膜堆栈，以及需要时的掩模 3D 效应。

imec、ASML Brion 与 ZEISS 在 High-NA EUV 上还研究了 AIMS 空中像的直接用途。AIMS 使用与扫描机照明对应的条件观察工作波长空中像，可以提供 ILS、对比度、SRAF 图像和跨焦点图形偏移，并帮助分离掩模参数与后续光刻胶效应。[[26]](https://doi.org/10.1117/12.2688109) 它不能替代最终晶圆校准，却能让掩模和空中像子模型少依赖后级参数补偿。

掩模模型负责从设计掩模转到真实掩模透过率。光学模型负责从掩模到空中像。光刻胶模型负责从空中像到显影后轮廓。三个模块分开后，掩模 CD 或光源更新可以在一定范围内替换相应输入，避免所有变化都重新拟合进光刻胶模型项。

分开并不意味着完全独立。参数之间仍可能补偿。例如错误的光源形状可以被光刻胶阈值部分吸收，错误的掩模 CD 可以被 全局偏差吸收。工程师会先固定高可信度物理参数，再逐步释放少量待拟合参数，同时查看不同图形和不同条件的残差签名。

紧凑模型还受一个很硬的约束，它要在全芯片上被调用许多次。严谨 Maxwell 求解器、完整光刻胶化学体系和等离子体仿真可以帮助理解局部物理，却很难直接承担全芯片 OPC 的反复迭代。工业模型因此选择一组计算得动、对关键变化足够敏感的状态量。校准工作的本质，是在物理完整性、可辨识性、预测精度和运行时间之间选一个能进入生产的抽象层次。

### 校准残差与预测误差

模型优化器总能把更多参数用于降低校准 RMS。参数过多时，模型会开始解释计量噪声、偶然晶圆波动和采样方案的偏差。训练集更准，未见图形和非标称条件反而更差。

所以验证要在拟合前划出。它应包含未参与校准的节距、二维环境、工艺条件或产品局部图形。工程师还会逐一查看各图形类别的残差，总 RMS 只是其中一个指标。残差若随节距单向漂移，说明邻近响应仍有遗漏。残差若随焦点位置改变符号，可能是光源、像差或焦点位置模型有问题。随机散布很大时，先查计量和工艺波动，再考虑增加模型自由度。

这套方法把模型评价从曲线拟合变成了有边界的预测。模型只对经过数据覆盖和独立验证的设计间隔、工艺窗口、扫描机配置与材料堆栈负责。超出这个范围时，正确动作是补实验或限制使用域，不能用已有 RMS 代替证据。

### CD-SEM 观测模型

晶圆图像中的边缘位置受到计量过程影响。电子束和光刻胶会相互作用，着陆能量、扫描方向、帧数、电流密度和充电效应都会改变图像。薄 EUV 光刻胶尤其容易发生收缩。

Mack 等人的建模计量研究使用 221 个一维图形、728 个跨焦点和剂量量测结构，并划分校准与验证。把 CD-SEM 的系统偏差作为计量模型加入后，验证表现得到改善。[[12]](https://doi.org/10.1117/12.2218534)

imec 联合实验则比较 500 eV 与 150 eV 的 ADI 成像。低着陆能量降低了光刻胶收缩，却带来更低的信噪比和更高的轮廓提取 要求。团队用同一组 AEI 轮廓分别配对两种 ADI 轮廓，得到两套刻蚀偏差数据。结果显示，ADI 量测方式的变化会一路传递到刻蚀模型残差。[[8]](https://doi.org/10.1117/12.3010898)

TSMC 在 2026 年公开的一项专利申请也直接描述了计量感知 OPC。方案从同一晶圆的多张图像建立计量误差函数，把计量模型与 OPC 模型串联，并允许用后续晶圆图像继续训练。[[13]](https://patents.google.com/patent/US20260003293A1/en) 专利不等于量产披露，但它清楚展示了先进晶圆厂正在处理的问题。模型看到的晶圆图像也需要被建模。

## 目标调整与掩模修正

正向模型从掩模预测 ADI 或 AEI，逆向求解则沿相反方向工作。若最终目标在 AEI，先对刻蚀或目标调整求逆。

AEI 目标⟶ADI 目标

再对光刻或 OPC 求逆。

ADI 目标⟶掩模图形

这两步解释了 SSA、刻蚀补偿与 OPC 的分工。SSA 或目标调整先决定 OPC 应该追逐什么晶圆目标，OPC 再移动掩模边缘去实现这个目标。两步都表现为尺寸变化，优化对象却不同。

### SSA 对目标轮廓的调整

SSA 常被展开为 Selective Size Adjustment。它修改的是 OPC 的晶圆目标。随后 OPC 再根据这个新目标求掩模形状。

这种操作的动机来自共同工艺窗口。某些forbidden-dense-alternate 图形即使标称条件 CD 能对准，在焦点位置或剂量改变时也可能比其他图形更快越过规格。工程师可以对特定宽度、间隔或图形类别预先加一个目标偏差，让不同图形的 Bossung 曲线和工艺窗口更好地重合。

因此，SSA 偏差通常不能只取标称条件 CD 误差的相反数。它还要考虑焦点位置、剂量、MEEF、NILS、最终电性目标、设计规则、掩模规则和相邻图形的共同窗口。

### SSA 表与共同工艺窗口

公开专利给出了一条很直观的路径。[[14]](https://patents.google.com/patent/CN119516574A/zh)

1. 设计一组宽度和间隔测试图形，并按图形类别组织。
2. 在扫描机上做焦点位置和剂量步进扫描，完成曝光和显影。
3. 量测不同条件下的光刻胶宽度，画出 Bossung 和工艺窗口。
4. 为每个 CD 与间距组合求使共同窗口达标的目标调整量。
5. 把结果整理为按目标 CD、间隔、图形极性或图形类别索引的偏差表。
6. 在 OPC 前将表应用于设计目标，再运行 OPC 和全芯片验证。

中国科学院微电子研究所的公开专利 CN110989289A 描述了对forbidden-dense-alternate 图形作选择性展宽的目标调整方案。[[15]](https://patents.google.com/patent/CN110989289A/zh) 它可说明目标调整的动机，但不能据此断言所有机构都将该流程命名为 SSA，或该专利方案已进入量产。 Applied Optics 上的相关论文进一步展示了这类目标调整对共同工艺窗口的作用。[[16]](https://doi.org/10.1364/AO.57.007811)

真实流程往往还会把仿真放进循环。模型可以先扫大量宽度、间隔和条件，缩小需要上晶圆的组合。晶圆数据再校正模型与规则表。若产品热点落在表覆盖范围以外，就需要新增测试图形或转向基于模型的目标调整。

这里的方法仍然是先用模型扩展搜索，再用晶圆确定现实边界。仿真适合低成本扫描大量组合，晶圆实验负责发现模型没有描述的效应。表是这轮搜索的压缩结果，它必须带着适用的 CD、间隔、图形极性、工艺条件和图形类别一起发布。

### SSA 缩写的其他用法

一些晶圆厂资料也会把补偿 ADI 到 AEI 差异的尺寸调整表称为 SSA 表。此时它承载的是刻蚀偏差或图形转移偏差。

两类表的建立方法相似，都按图形环境整理偏差，也都在 OPC 前修改目标。物理目标却不同。一类处理光刻工艺窗口，另一类处理光刻胶到最终薄膜的图形转移。实际项目应先看表的输入和输出定义，再判断内部缩写指向哪一类。

## 刻蚀模型与最终轮廓预测

### 工艺开发与 OPC 校准数据

刻蚀工程师为开发配方会收集许多数据，包括无图形薄膜刻蚀速率、选择比、晶圆内均匀性、腔体匹配、终点信号、等离子体条件、剖面、侧壁角、深度、残留和材料损伤。

OPC 刻蚀模型的目标更窄。它需要在全芯片上快速预测图形转移对边缘位置的系统影响。主要数据是同一类图形环境下的 ADI 和 AEI 配对。

一个常用定义是

$$ b_{\mathrm{etch}}=\mathrm{CD}_{\mathrm{AEI}}-\mathrm{CD}_{\mathrm{ADI}}. $$

对二维图形，工程师更关心沿轮廓的局部位移。线端、内角、外角、接触孔的不同方向可以有不同偏差。局部图形密度、开口区、图形可见性、相邻结构、底层材料和光刻胶剖面都可能参与。

Gardin 等人的 65 nm 刻蚀建模研究显示，简单宽度和间隔规则在复杂图形环境中会遇到覆盖边界，紧凑刻蚀模型需要描述局部密度与邻域影响。[[17]](https://doi.org/10.1016/j.mee.2007.01.085)

### ADI 与 AEI 的配对要求

理想做法是为同一个设计位置获取 ADI 与 AEI 轮廓。数据采集需要考虑电子束对胶的影响：ADI 的 SEM 量测本身可能让光刻胶收缩，影响后续刻蚀。

一项接触孔工艺层研究采用同一晶圆、不同曝光场的方式采集 ADI 与 AEI，避免在待刻蚀位置上重复电子束照射。研究覆盖约 40 类接触孔构型，每类量八个曝光场。约三分之一结构用于校准，其余用于验证。轮廓上每隔约 5 nm 放置 EPE 样本，一个结构可以产生约 500 个局部数据点。[[18]](https://doi.org/10.1117/12.2248013)

imec 的 2024 年实验采用四片晶圆，把光刻与刻蚀、标称条件与工艺窗口分开。对 1D 和 2D 图形都保留重复量测，并将 ADI 轮廓与 AEI 轮廓重叠形成刻蚀偏差。[[8]](https://doi.org/10.1117/12.3010898)

对先进节点，只量俯视 CD 可能仍然不够。相同顶部 CD 可以对应不同侧壁角和光刻胶 3D 剖面，进入刻蚀后产生不同横向侵蚀或剖面转移。Wu 等人的研究将光刻胶 3D 仿真与紧凑刻蚀模型连接，明确讨论了侧壁角、离子能量、角度分布、气体、压力和材料刻蚀速率等因素。[[19]](https://doi.org/10.1117/12.2086048)

量产 OPC 模型不可能把整个等离子体反应腔的多尺度物理都逐点算一遍。工程师会选择与晶圆数据有稳定相关性的少量描述量，压缩成高斯核、可见性核、密度核或其他经验基函数。压缩得过度会漏掉二维行为，基函数太多又容易过拟合。

### 分阶段、整体与目标调整流程

| 方式 | 校准对象、优点与风险 |
| --- | --- |
| 整体模型 | 校准对象<br>直接用 AEI 数据拟合一个总模型<br>优点<br>流程简单，直接瞄准最终图形<br>风险<br>光刻与刻蚀根因混在一起，换任一工艺后维护困难 |
| 目标调整流程 | 校准对象<br>用 ADI 到 AEI 偏差生成目标调整量<br>优点<br>速度快，容易进入现有 OPC 校正流程<br>风险<br>表或简单模型覆盖不了复杂二维环境 |
| 分阶段模型 | 校准对象<br>先建光刻模型，再建 ADI 到 AEI 的刻蚀模型<br>优点<br>物理边界清楚，可分别验证<br>风险<br>数据配对和模型管理更复杂 |

公开专利 US8255838B2 详细讨论了 staged、目标调整与 lumped 的差别，并用 ADI 晶圆、ADI 模型和 AEI 晶圆之间的残差构建刻蚀感知校准。[[20]](https://patents.google.com/patent/US8255838B2/en) 工厂选择哪一种，还取决于工艺层、工艺稳定性、运行时间、现有工具和维护成本。

三种方式代表三种模型分解假设。整体流程假设集成工艺足够稳定，可以直接学习掩模到 AEI 的总响应。目标调整流程假设主要刻蚀效应能压缩成目标偏差。分阶段流程假设光刻与刻蚀可以通过 ADI 量测有效分开。工程师会用留出集结构、工艺变更和运行时间去检验这些假设。某种模型在一层金属层上有效，不代表它能直接搬到接触孔、离子注入层或另一套刻蚀堆栈。

这里还有一个维护问题。光刻胶或光源经常变化，而刻蚀相对稳定时，分阶段模型允许只更新光刻部分。两段数据很难可靠配对，或者最终 AEI 才是唯一可信量测时，整体模型可能更现实。模型结构应当服从数据能支持的因果分解，不能反过来要求数据证明一个预先选好的软件结构。

## 模型验证与生产资格

模型开发在反演与实物验证之间迭代。当前模型提出光源、目标偏置和掩模候选，实验检验这些候选在扫描机、光刻胶与刻蚀过程中的响应。新出现的偏差用于修订采样方案或模型结构。

各阶段通常需要迭代。新的晶圆热点可能说明采样方案没有覆盖某类二维环境，团队要把它放回测试载体。实测光源与目标光源的偏差可能要求重新光源映射，也可能要求重建模型。AEI 残差若只在某种底层材料上出现，刻蚀模型的输入边界就要扩大。

全芯片验证在这里承担一个特殊角色。测试掩模用有限样本建立模型，产品版图却包含数量巨大的局部环境。验证规则集用紧凑模型扫描整片设计，寻找超出校准覆盖范围、工艺窗口过窄、MRC 冲突和迭代不收敛的位置。它把有限实验和全芯片图形空间接起来，但最后的资格验证仍要回到新掩模版与晶圆。

TSMC 对外介绍掩模服务时，明确称其 OPC 模型覆盖晶圆工艺设备、工艺材料和可制造性设计（DFM）要求，并维护经过晶圆验证的 OPC 数据库。[[21]](https://www.cld.tsmc.com/english/dedicatedFoundry/services/mask_services) TSMC 对 N6 的公开描述也把光刻工艺优化、OPC 和刻蚀协同优化放在同一量产技术路径中。[[22]](https://www.cld.tsmc.com/english/dedicatedFoundry/technology/platform_DCE_N7_N6) 这些官方材料没有公布内部配方，能够支持的判断仍然很清楚。量产资格验证面向整套工艺、模型与设计规则的组合。

## High-NA 模型的分阶段建立

大多数流程默认先有稳定扫描机和工艺，再收晶圆数据建模型。High-NA EUV 的首次导入打破了这个顺序。

Intel 在 2024 年完成首台商用 EXE 5000 的安装后，公开说明设备仍要经过校准才能服务未来工艺路线图。[[23]](https://www.intel.de/content/www/de/de/newsroom/news/intel-foundry-opens-new-frontier-chipmaking.html) 设备、掩模、光刻胶、刻蚀、计量和 OPC 的开发必须并行，否则所有工作都排在扫描机验收之后，学习周期会很长。

Chris Mack 对 2025 年 SPIE 会议的记录提到，Intel 的 Can Guven 介绍了一种提前校准思路。团队在扫描机发货前量测像差，再对最终光学调整后的状态做预测，用严谨仿真推断早期晶圆结果与预期最终结果的差异，从而让 OPC 校准更早开始。[[24]](https://lithoguru.com/life/?p=736)

这个案例的价值在于展示物理量测与仿真的另一种连接方式。晶圆数据仍然重要，但它不一定要等所有硬件和工艺完全冻结后才出现。高可信度的掩模、像差和空中像仿真可以先建立开发阶段模型，早期晶圆用来更新它，进入稳定工艺后仍需用独立晶圆与产品图形完成资格验证；这是本文提出的工程验证要求，不是该会议笔记已经证明的实施结果。

这是一种渐进式精度策略。早期模型用已知物理量和严谨仿真回答架构问题，帮助准备测试掩模与初始 OPC。扫描机安装后的早期晶圆负责修正机台特定响应。工艺与材料稳定以后，最终资格仍应由稳定工艺下的独立晶圆与产品验证承担。每一阶段的模型都有清楚的证据等级和使用限制。

这种做法能缩短串行等待，却没有取消晶圆验证。它只是把原本集中在扫描机就绪之后的学习拆到多个阶段并行进行。越早期的模型越依赖物理先验，越接近量产的模型越要接受产品图形、真实工艺窗口和计量的约束。

这段早期校准信息来自 Mack 的署名会议笔记，作者同时提醒转述可能遗漏或误解细节；它不构成 Intel 官方的量产资格披露。它适合说明一种先进开发策略，不适合写成 Intel 已公开的完整量产配方。

## EUV 概率模型与失效数据

ArF 时代的紧凑模型主要关注系统性 CD 和 EPE。EUV 中的光子、二次电子、光刻胶化学体系和材料随机性会产生 LER、LCDU、接触孔缺失、微桥等概率事件。

平均轮廓对系统误差很有用，却会抹平随机缺陷。工程师需要在同一图形、同一条件下采集更多重复 SEM 图像，把平均边缘、方差、空间相关性和缺陷概率分开处理。用于高 σ 缺陷预测的实验数量会非常大，严谨 Monte Carlo 仿真也承担一部分数据生成任务。[[25]](https://doi.org/10.1117/12.3093415)

未来的 OPC 模型包可能同时包含两个模型。一个预测平均轮廓与工艺窗口，另一个预测在该平均条件周围发生随机失效的概率。两者会共享光源、掩模、光刻胶和计量数据，却有不同的采样设计和验证指标。

系统模型依靠跨图形和跨条件的受控差异，概率模型还需要同一条件下的大量重复样本，以估计分布尾部和罕见缺陷概率。重复 SEM 图像的平均处理保留平均轮廓，却会丢失概率模型所需的波动信息。

## 模型适用域与持续维护

校准 RMS 反映参与拟合样本的残差。生产资格还要求独立图形、多工艺条件和实际掩模、晶圆结果共同支持模型的适用范围。

发布的对象是一组兼容关系。模型版本要绑定光源、扫描机配置、掩模堆栈、光刻胶与膜堆栈、刻蚀腔体类别、计量配方、OPC 校正流程、MRC 和验证规则集。脱离这些状态单独复制一个模型文件，原有验证结论就失去了适用条件。

当设备、材料、计量或校正流程发生变化，工程团队要判断改动是否仍在模型适用域内。小变化可以通过重新资格验证证明兼容，超出适用域的变化则需要补数据、更新参数、重建模型或限制模型使用范围。

这项判断可以分三层。受控波动仍在原校准分布内时，量产监控负责确认。可独立量测的物理输入改变，但模型形式仍有效时，可以替换输入并做针对性重新资格验证。新的工艺响应特征落到覆盖范围以外时，团队要重新设计分组实验、补校准与验证数据，再发布新的模型包。

## 参数可辨识性与局部敏感度

参数补偿可以通过局部敏感度分析检验。设第 $i$ 个实验输入是 $\mathbf x_i$，模型参数为 $\boldsymbol\theta$，预测量为 $g_i(\mathbf x_i;\boldsymbol\theta)$。实际量测可进一步写成

$$
\mathbf y=\mathcal H\!\left(\mathcal F(\mathbf x;\boldsymbol\theta);\boldsymbol\phi\right)
+\boldsymbol\epsilon.
$$

$\mathcal H$ 是计量与抽边过程，$\boldsymbol\phi$ 是计量参数，$\boldsymbol\epsilon$ 是随机误差。输入 $\mathbf x$ 本身也可能有不确定度，例如扫描机的实际焦点、剂量和掩模 CD。把这些量全当成精确常数，会迫使工艺参数吸收输入误差。Mack 的校准研究讨论了稳健回归与总体最小二乘；它说明损失函数的选择必须服从实际误差位于哪里。[[11]](https://doi.org/10.1117/12.728961)[[12]](https://doi.org/10.1117/12.2218534)

若先采用输出噪声模型，残差 $\mathbf r=\mathbf y-\mathbf g(\boldsymbol\theta)$ 的加权目标可写为

$$
\widehat{\boldsymbol\theta}=\arg\min_{\boldsymbol\theta}
\mathbf r^\mathsf T\Sigma^{-1}\mathbf r
+\lambda R(\boldsymbol\theta),
\qquad \boldsymbol\theta\in\Theta_{\mathrm{phys}}.
$$

$\Sigma$ 是量测协方差，$\Theta_{\mathrm{phys}}$ 是物理可接受参数域。CD 点若来自同一曝光场，共同的焦点位置偏差会使它们相关；一条 SEM 轮廓上相邻点也不独立。用对角矩阵代替全部协方差是可以采用的工程近似，但要评估这种近似是否造成某些轮廓被过度加权。

辨识能力由噪声归一化的敏感度决定。对参数作局部线性化：

$$
\Delta\mathbf y\approx J\Delta\boldsymbol\theta,
\qquad J_{ij}=\frac{\partial g_i}{\partial\theta_j},
\qquad A=\Sigma^{-1/2}J=U\operatorname{diag}(s_k)V^\mathsf T.
$$

很小的奇异值 $s_k$ 表示沿对应参数组合改变，预测响应仍被噪声淹没。此时得到唯一的优化器输出，不等于数据给出了唯一的物理解释。多 NA、多节距和多图形数据联合校准，能够增加独立约束，但仍要检查它们是否真的改变敏感度方向。[[27]](https://doi.org/10.1016/S0167-9317(02)00438-0)

例如只用标称 CD，同时放开光源模糊、光刻胶扩散、SEM 模糊，三个参数都可能让边缘变缓。增加同节距的重复点主要降低噪声，不一定能分开它们。引入独立光瞳量测、PEB 分组实验、不同着陆能量的 SEM 数据，才有机会让三种机制留下不同签名。即便如此，若工艺本身变化不可控，结论仍可能是“只能识别一个有效模糊”，应诚实保留这个抽象。

对非线性模型，SVD 是局部工具。还可以固定某个参数，在一系列值上重新优化其他参数，画出剖面损失；若很宽的参数范围都具有相近损失，其不确定度就不能用单次优化器的收敛标志掩盖。不同初值、多批次自助重采样和独立物理量测，也有助于检验结论是否依赖偶然样本。

## 实验信息量与样本选择

在局部近似下，实验的信息矩阵是 $F=J^\mathsf T\Sigma^{-1}J$。这给出选择采样方案的一种数学语言：增加 $\log\det(F+\alpha I)$ 可鼓励覆盖多个敏感方向，提高最小特征值可优先补最难辨识的方向。$\alpha$ 是避免奇异的正则项。这些是一般实验设计准则，本文不声称某家工厂按同一公式选晶圆。

像素数与独立信息量并不成比例。同一二维图形上的数百个 EPE 点可能共享配准和抽边偏差；重复晶圆、重复芯片及测量方向变化用于估计这种相关性，新节距、方向及工艺分组则可能增加新的敏感度方向。

一个具体决策例子是：模型在离焦的线端上出现同向残差，而标称条件长直线已经足够好。下一轮优先收集对焦点与二维方向敏感的图形，并确认实际焦点位置与掩模轮廓；再收一批相同标称条件长直线，很可能只是重复已有约束。若怀疑刻蚀，不应先释放更多光学参数，而要补能可靠配对的 ADI/AEI 或剖面信息。

IBM 的自动样本选择研究给出在设计覆盖与量测成本之间折中的实际例子；多阶段回归研究则说明，增加模型复杂度和提高验证精度并非同一回事。[[7]](https://doi.org/10.1117/12.2086049)[[28]](https://research.ibm.com/publications/multiple-stages-of-regression-to-improve-accuracy-in-calibrated-lithography-process-models) 数学准则用于提出候选，最终采样方案还要满足测试掩模面积、晶圆数量、SEM 寻址与工艺可执行性。

## 数值误差、模型误差与观测误差

数值收敛是第一层。固定模型、输入与参数，分别增加电磁网格、源点采样、SOCS 核数和像面分辨率，检查预测及其优化梯度是否稳定。若每次增加核数又重拟合胶参数，数值变化与参数补偿混在一起，就无法判断光学算法本身是否收敛。

第二层才是预测验证。保留拟合结果，预测没有参与调参的数据。随机把相邻量测结构分成两组可能泄露几何和工艺信息；若实际任务是预测新产品或新晶圆，留出集应按图形家族、独立晶圆或独立条件分组。为了选择模型复杂度使用的验证，也不能在最后继续当作从未看过的测试集。

第三层是逆问题验证。一个前向模型能够预测固定局部图形，不代表其梯度对求解器足够准确。OPC/ILT 会主动寻找模型认为有利的形状，也可能走向训练覆盖之外。应当用更高精度仿真或独立模型检查最终掩模，再用写后掩模和晶圆验证。这个检查尤其应覆盖新出现的高曲率、细小 SRAF 和极端邻域。

评价量应包括：按图形和条件分箱的偏差、分位数与最大 EPE、工艺窗口交集、形貌与连通性失败，以及整套验证的运行时间。全局 RMS 容易被数量多的简单图形支配；某个关键端到端的稳定失败，不应被平均掉。

计量误差与模型误差还要分别估计。重复量测可以近似估计精密度，不能单独证明准确度；同一 SEM 配方稳定地把所有边缘偏移，重复一百次仍会稳定地偏。必须结合量测模型、独立计量或已知物理变化，识别这类系统偏差。[[12]](https://doi.org/10.1117/12.2218534)

## 不确定度传播与变更控制

如果输出边缘为 $\mathbf c(\boldsymbol\theta)$，参数协方差为 $\Sigma_\theta$，局部传播为

$$
\Sigma_c\approx G\Sigma_\theta G^\mathsf T,
\qquad G=\frac{\partial\mathbf c}{\partial\boldsymbol\theta}.
$$

这个结果只反映已定义模型与参数的不确定度，不包含遗漏物理的系统偏差。若不同合理模型在训练集同样好、在某类产品图形预测分歧很大，这种分歧本身就应触发额外验证。不能因为参数置信区间很窄，就宣布模型形式误差也很小。

对缺陷概率，验证要求又不同。若 $N$ 次独立机会中零失败，单侧 95% 上界为 $1-0.05^{1/N}\approx3/N$。当声称的失效率远低于这个上界，必须说明额外证据来自更大规模实验、重要性采样、物理概率模型还是未经验证的外推。真实晶圆的空间相关性还会减少有效独立样本数。平均 CD 的标准误无法替代稀有失效概率的置信区间。

因此模型发布应带着一份明确的适用域声明：目标平面、图形类别、焦点位置/剂量范围、掩模/光刻胶/刻蚀/计量版本、数值精度以及独立验证证据。换光源可能主要影响光学输入，换 SEM 配方首先改变观测链，换刻蚀化学体系则可能改变整个模块的函数形式。变更控制要根据受影响的因果路径选择实验，而不能对所有变化一律套用同一小组监控。

模型记录需要保存系数、约束这些系数的数据依据、有效参数的解释范围，以及使验证结论失效的工艺条件。

## 建模流程与验证交付物

建模流程需要将数据选择、模型自由度和预测资格联系起来。换层、光源、光刻胶或刻蚀堆栈时，原有证据的有效性取决于受影响的物理过程与观测环节。

下面按目标、模型、数据、求解和验证组织交付物。这是对公开实践的工程归纳，适用于本文讨论的有限实验与全芯片紧凑模型场景。

| 阶段 | 主要动作 | 交付物 | 失效信号 |
| --- | --- | --- | --- |
| 目标定义 | 选定 ADI 或 AEI 目标，分配 EPE 预算，定义标称与工艺窗口指标 | 目标规格、误差预算与验收指标 | 模型残差无法关联产品几何或器件要求 |
| 模型分层 | 建立掩模、光学、胶、刻蚀和计量的前向关系，固定可独立量测的输入 | 模型边界、参数归属与量测清单 | 参数相互补偿，工艺变化后无法定位误差来源 |
| 实验辨识 | 设计节距扫描、FEM、掩模偏置、工艺分组、重复芯片和 ADI/AEI 配对，预留验证样本 | 测试载体、采样方案、计量配方与不确定度估计 | 增加量测仍未增加独立信息 |
| 紧凑建模 | 分层校准，检查分类残差、非标称条件和独立验证 | 模型包、验证报告、适用域与运行时间 | 校准误差较低而留出图形出现稳定偏差 |
| 受约束反演 | 多条件求解 SMO、SSA、OPC 或 ILT，落实照明器、MRC 和复杂度约束 | 照明规格、SSA 表、OPC 流程、掩模图形与验证规则 | 设备无法实现照明、掩模不可制造或共同窗口不足 |
| 资格管理 | 量测实际光源，写入掩模并曝光产品晶圆，核对缺陷与电性，绑定工艺及计量版本 | 晶圆资格验证、兼容版本、监控与重新验证规则 | 模型脱离原扫描机、材料、刻蚀或计量条件使用 |

这些阶段是本文对公开案例的归纳。imec 在不同工艺状态下进行计量实验，用于分离过程与观测效应。[[8]](https://doi.org/10.1117/12.3010898) GlobalFoundries 在优化光源上重新收集数据、建立模型并制作新掩模，说明照明改变后需要更新模型证据。[[2]](https://doi.org/10.1117/12.916614) Intel 的安装公告及 Mack 的署名会议笔记涉及硬件校准与早期模型开发；本文将其组织为开发、早期晶圆和最终资格验证阶段，后一个阶段并非会议笔记已经证明的结果。[[23]](https://www.intel.de/content/www/de/de/newsroom/news/intel-foundry-opens-new-frontier-chipmaking.html)[[24]](https://lithoguru.com/life/?p=736) TSMC 关于晶圆验证 OPC 数据库以及光刻、OPC 与刻蚀协同优化的公开说明，也将适用性关联到工艺和模型的组合。[[21]](https://www.cld.tsmc.com/english/dedicatedFoundry/services/mask_services)[[22]](https://www.cld.tsmc.com/english/dedicatedFoundry/technology/platform_DCE_N7_N6)

这六步有三次方向变化。产品要求先沿制造过程向上游逆推，决定目标、误差预算、模型边界和实验内容。设备、掩模、晶圆与计量数据随后沿正向过程建立模型，回答给定输入会印出什么。正向模型通过独立验证以后，求解器才沿逆向过程计算光源、目标偏差和掩模图形。最终解回到扫描机、掩模版和晶圆，接受实物检查。

实验应针对待区分的效应设计。跨节距量测约束邻近响应，FEM 约束焦点位置和剂量斜率，掩模偏置分组识别掩模响应，ADI 与 AEI 配对分离光刻和刻蚀，重复芯片估计噪声，留出图形检验预测。每类数据提供的约束方向不同，量测数量本身无法替代这种区分能力。

模型自由度也应服从同一原则。一个参数只有在数据中留下可区分的签名，才有理由成为拟合自由度。能独立量测的光源、像差、掩模 CD 和膜堆栈应尽量作为物理输入。难以直接分离的光刻胶、刻蚀和计量效应可以交给拟合，但它们需要接受跨图形、跨条件和独立样本的残差检查。训练误差无法替代这些证据。

每次模型发布最后都应当写成一条带条件的资格声明。它说明模型预测哪个目标，覆盖哪些设计图形和工艺窗口，绑定哪组扫描机、光源、掩模、光刻胶、刻蚀与计量版本，并在多大的误差预算内通过了哪些独立验证。任何一项条件改变，团队都要重新判断原证据是否仍然成立。

实验约束可解释的参数组合及模型适用范围，仿真在该范围内评价大量光源与掩模候选，新晶圆再检验反演结果。工艺或计量变化后，模型维护需要定位失效的证据，并据此选择补充实验。
