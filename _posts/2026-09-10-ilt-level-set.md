第一次看 ILT 生成的掩模，很容易觉得它画坏了。原本方正的线端长出弯曲的帽檐，转角被掏去一块，主图形旁边还会冒出细小的辅助结构。掩模与芯片设计稿越来越不像，晶圆上的图形反倒更接近目标。反演光刻的脾气就在这里。ILT 的全名是 Inverse Lithography Technology。常规光刻仿真从掩模出发，计算晶圆上会印出什么。ILT 把方向倒过来。它先拿到晶圆目标，再反求一张合适的掩模。方向倒过来以后，麻烦也跟着来了。掩模是黑白二值图形，优化器却擅长在连续变量上算梯度。图形边界还可能分裂、合并，凭空长出一个孔洞或一条亚分辨率辅助图形。若用一串首尾相接的控制点描述轮廓，每次拓扑变化都得重新整理点与点的关系。Level Set 专门处理这种边界。我对照了 2009 年以来的 Level Set ILT 论文、两本经典数值方法专著，还有近年的产品资料和专利，想弄清一件具体的事。一条会改变形状甚至改变连通关系的掩模边界，究竟怎样交给优化器。一条边界怎样藏进一个函数Level Set 的中文常译作水平集。这个名字有点抽象，做法却很具体。先在整张二维网格上定义一个标量函数 ϕ(x,y)。可以把它理解成每个位置都有一个带正负号的数。我们规定图形内部为正，外部为负，正负刚好交界的地方就是掩模轮廓。Γ={(x,y)∣ϕ(x,y)=0},M(x,y)=H ⁣(ϕ(x,y))这里的 Γ 是边界，M 是送进成像模型的二值掩模。H 是 Heaviside 函数，它把 ϕ 的正值映成 1，把负值映成 0。实际计算会使用平滑后的 H，否则零点附近无法稳定地求导。假设一个圆形区域由ϕ(x,y)=r−x2+y2表示。圆内的 ϕ 为正，圆外为负，ϕ=0 恰好落在半径为 r 的圆周上。优化时不用逐个拖动圆周上的点，只要改变整张 ϕ 场，零等值线就会随之移动。两个闭合轮廓可以在演化中碰到一起并合并，一个闭合轮廓也可以收紧后分成两块。算法一直更新同一张标量场，不必在变化发生的那一刻停下来重建拓扑关系。1988 年，Stanley Osher 和 James Sethian 用 Hamilton-Jacobi 方程系统建立了这套界面传播方法。[1] 后来的两本专著又讲清了迎风格式、窄带计算和重初始化等数值技术。[2][3]Level Set 比 ILT 年长。它先用于火焰传播和流体界面，之后才进入逆问题与光刻。把两者直接画等号会漏掉很多东西。ILT 是从晶圆目标反求掩模的任务，Level Set 是一种掩模表示与边界演化方法。像素法、显式轮廓、样条曲线和神经网络同样可以参与 ILT。优化器让边界往哪里走有了 ϕ，还要回答另一件事。边界往哪里走。一套简化的 Level Set ILT 目标可以写成J(ϕ)=∑kwk
D ⁣(F ⁣(H(ϕ);θk),T)+λR(ϕ)+μC(ϕ)这行公式装了四类信息。T 是希望在晶圆上得到的目标。H(ϕ) 给出当前掩模，F 是正向光刻模型，负责计算这张掩模在工艺条件 θk 下会印成什么样。D 衡量预测图形与目标的差距。下标 k 可以对应不同焦距、剂量、像差或其他工艺角，wk 决定每个条件有多重要。R(ϕ) 是几何正则项，用来压住过长的周长、过大的曲率和高频摆动。C(ϕ) 放制造约束，例如最小线宽、最小间距、最小曲率半径和图形连通性。λ 与 μ 则控制晶圆成像、几何平滑和可制造性之间的取舍。优化器根据 J 对边界的敏感度构造一个法向速度 Vn，随后更新整张 ϕ 场。∂ϕ∂t+Vn∣∇ϕ∣=0t 是优化迭代的时间，不是曝光时间。∇ϕ 指向函数增长最快的方向，它也给出了边界法向。Vn 的大小说明边界该走多远，正负号说明它向内收还是向外扩。符号会随内外区域的定义改变，几何含义不变。一次迭代大致是这样的。先由 ϕ 得到二值掩模，再跑一遍或多遍成像，计算晶圆误差，接着用伴随法或解析梯度求出边界敏感度，最后让 ϕ 沿法向走一小步。几十次到几百次更新以后，轮廓才逐渐稳定。这套过程很像 OPC 工程师熟悉的边移动，只是自由度更大。传统 edge-based OPC 通常移动已经存在的边段。Level Set 更新的是隐式场，新的边界有机会出现，旧边界也可以消失。SRAF 不一定要由规则预先放好，它可能在优化中自己长出来。为什么这套表示好用像素密度法常把每个掩模像素暂时放宽到 0 与 1 之间，优化结束后再阈值化。做法直接，也很适合 GPU 和自动微分。问题出在最后一步。灰度解一旦切回黑白，已经得到的晶圆图形可能变差，还容易留下锯齿、小岛和狭缝。Level Set 的起点不同。它从一开始就用正负号区分两个材料区域，连续变化发生在边界的位置，不必把半透明像素解释成真实掩模。零水平集还能落在网格点之间，轮廓位置不完全受像素中心约束。二值掩模与连续优化之间的麻烦，被挪到了边界上。拓扑变化更直观。ILT 经常要同时处理主图形和辅助图形。显式曲线若想新增一个封闭轮廓，需要另外创建控制点并决定连接关系。Level Set 只需让某片区域的 ϕ 穿过零点，一条新边界便出现了。边界法向、曲率和周长也能从 ϕ 直接计算，平滑轮廓或限制尖角比较自然。今天的曲线掩模正需要这种几何约束。优化器既要压低 EPE，也要让轮廓能被写版和检查，出了缺陷还得有办法修。2009 年，Yijiang Shen、Ngai Wong 和 Edmund Lam 在 *Optics Express* 发表题名明确写出 Level-set-based inverse lithography 的论文，把光刻掩模综合写成非线性图像恢复问题，并用水平集演化求解。[4] 同年，Pang 等人的 SPIE 论文把 Level Set ILT 扩展到全芯片 SMO。[5] 2011 年，Shen 等人又把离焦和像差等随机过程变量纳入期望代价，形成鲁棒 Level Set ILT。[6]把这几篇论文按时间连起来，方法的变化很清楚。2009 年先让边界按成像误差移动，2011 年又要求同一张掩模扛住离焦和像差，评价对象从一个标称点扩到了多个工艺条件。自由形状也要交制造费论文谈 Level Set，最常写的优点是自然处理拓扑变化。它解决了几何表示，收敛、计算量和制造限制仍要另外处理。拓扑自由扩大了搜索空间，却不给全局最优保证。ILT 的目标函数高度非凸，同一张目标图形可能对应许多局部解。初始掩模、平滑宽度、正则权重和时间步只要换一组，最后的轮廓就可能不同。某次拓扑变化若在数值上被压掉，后面的迭代也未必能把它找回来。计算量更直接。每走一步，往往都要对多个焦距和剂量条件执行前向成像与梯度计算。进入 EUV 以后，三维掩模、偏振、斜入射和随机效应会继续抬高单次模型调用的成本。窄带法只更新边界附近，多尺度方法先粗后细，GPU 把大量卷积与场计算并行起来，这些技术能省时间，却省不掉高保真模型本身。数值实现也有一套自己的窗口。时间步太大，边界会振荡或跨过合适位置。时间步太小，收敛很慢。ϕ 演化久了会偏离带符号距离函数，∣∇ϕ∣ 可能过大或过小，常要做重初始化。重初始化太频繁又会移动零水平集，细小结构可能被顺手抹掉。制造端更麻烦。若目标函数只奖励晶圆图形，求解器很乐意留下尖点、窄颈、小岛和紧挨在一起的细缝。它们在仿真里有用，到了掩模工艺修正、电子束写入、缺陷检查和修复环节，成本会迅速上升。早年的处理常把制造规则放在输出后清理。小图形删掉，尖角磨平，锯齿压掉。清理后的掩模已经变了，工艺窗口也要重新计算。近年的方向是让 MRC 更早进入迭代，用可微惩罚、几何投影或制造感知参数化约束每一步。2025 年的曲线规则研究已经在公开讨论如何让 ILT 输出直接满足曲线掩模规则。[7]三十多年里，问题换了几次Level Set ILT 的历史最好分成两条线看。一条是逆向掩模设计。Saleh 和 Sayegh 在 1981 年已经用图像恢复思路做掩模预补偿，算出了角部 serif。[8] 这项工作没有使用 ILT 或 Level Set 术语，却把后来反演光刻的方向提前摆了出来。2005 年，SMIC 与 Luminescent 公开了 65 nm ILT tape-out。论文摘要没有披露优化内核，因而只能证明 ILT 已进入芯片验证，不能拿它确认 Level Set。[9]另一条是隐式界面演化。1988 年的基础论文之后，1990 年代逐步补齐了高阶 ENO 格式、符号距离重初始化和快速窄带算法。2001 年前后，Level Set 开始系统进入逆界面与形状重建问题。2009 年，两条线在公开的 ILT 论文中清楚地合到一起。[1][4]2010 年代的重点从能否优化移到能否稳妥地优化。鲁棒目标把焦距、剂量和像差放入同一套代价函数。共轭梯度、线搜索与正则化用来改善收敛，更细的光刻模型也开始替代早期的简化近似。[6][10]2020 年代又换了一组约束。多束电子束写版降低了复杂曲线相对 VSB 写版的 shot 数惩罚，GPU 缩短大规模成像和梯度计算，原生曲线的数据、MRC、MPC 与检查流程随之成为新的焦点。Pang 在 2021 年把 ILT 的产业演进概括为从概念走向实用全芯片流程。[11] 2023 年的 *ACS Photonics* 综述仍把 Level Set、泛函导数和伴随计算列为 ILT 的核心数学工具。[12]早期论文只需说明自由形状求得出来。进入 2020 年代以后，同类工作还得交代曲线数据怎样通过 MRC、MPC、写版和检查。缺了这些信息，单看 wafer loss 已经很难支持量产判断。今天的论文在解决什么现在的论文若只给一张漂亮的自由曲线掩模，已经很难说明多少问题。全芯片运行时间仍是硬约束。分块可以把大版图交给多张 GPU 并行计算，但光学影响会跨过块边界，halo 区域和拼接一致性必须处理。2025 年刊出的自适应分块 Level Set 工作就在处理这件事。[13]神经网络则被拿来少走几步。它可以预测较好的初值、更新方向或快速成像代理，Level Set 再用物理模型完成校正。2023 年的 physics-informed deep neural level set 和 DevelSet 都用了这种组合。[14][15] 成像模型与制造签核仍然要跑，网络省下的是一部分搜索时间。制造规则也开始直接进入目标函数。曲率平滑通常能减少细碎结构和写版负担，也可能轻微牺牲图形损失或工艺窗口。DevelSet 的公开结果同时给出了这两面。[15] 减少图形复杂度会付出一点成像代价，惩罚权重还要按工艺重新调。许多 GPU 与神经 Level Set 论文仍主要使用 ICCAD 2013 的 32 nm clips、Hopkins 成像和恒阈值胶模型。这些结果能说明算法可以加速或混合，无法给出现代 EUV 全芯片的周转时间，也代替不了晶圆验证。到了 High-NA EUV，三维掩模、中心遮拦、anamorphic 成像、材料吸收和方向相关效应都要进入模型。EUV 的 microbridge、断线、接触孔缺失与合并还带有光子和胶化学引起的随机性。现有 robust Level Set 多数优化焦距、剂量和像差，直接优化随机失效概率的公开工作仍然很少。曲线产品的内核，公开资料说得很少看到某款商业工具输出曲线掩模，不能据此判断它内部使用了 Level Set。我查产品资料时，原本想确认哪些商用 ILT 仍在使用 Level Set。公开材料够不到这么深，只能把问题缩小。Synopsys Proteus 的官方页面可以确认生产部署、全芯片、原生曲线 ILT、HPC 与 SMO 等能力。Synopsys 在 2012 年收购了 Luminescent 的 Mask Synthesis 技术，也持有明确讨论 Level Set ILT 的专利。[16][17] 当前产品页没有公开 Proteus 的内部表示。它有 Level Set 的历史和知识产权证据，现行版本是否在所有流程中使用这套内核，外部无法确认。Siemens 的公开论文提供了一个很好的反例。其 pxOPC 曲线 ILT 被作者明确称为 pixel-based optimization，并用 image gradient 指示掩模运动。[18] D2S TrueMask 已公开 GPU、stitchless 和全芯片曲线 ILT 能力，当前资料同样没有确认 Level Set。[19]ASML 的专利描述过使用 level-set image 生成曲线掩模，产品技术页却没有把这项专利绑定到某个具体 SKU。[20] NVIDIA cuLitho 能加速计算光刻，并已与晶圆厂和 EDA 工具链集成，它是计算平台，不能被当作一种特定 ILT 优化器。[21]商业 ILT 通常还是一套混合系统。热点识别、初值生成、像素优化、隐式边界、显式曲线、规则投影、轮廓压缩和最终验证，可能在不同阶段接力。厂商也可能按图形、层和节点切换方法。产品页能说明工具交付什么。要确认算法内核，仍得看论文和专利。至于某种方法在什么工艺条件下有效，客户的掩模与晶圆数据更有分量。把这几类材料混在一起，很容易把产品能力写成算法结论。High-NA 以后，它会退场吗我的判断是，Level Set 不会消失，纯 Level Set 会越来越少。像素法适合大范围搜索和并行计算，神经网络适合预测初值与常见修正，Level Set 擅长处理拓扑和连续边界，样条或 Bézier 曲线适合压缩数据并直接施加曲率约束。把一项任务从头到尾交给同一种表示，未必是最省时间的做法。目前已经能看到一种混合路线。网络或像素优化先给出全局初值，Level Set 接着处理关键区域的拓扑与边界，最后投影成满足 MRC 的原生曲线。高成本三维模型也不会每轮覆盖全芯片。低阶模型负责大部分搜索，高保真模型盯住热点和最终签核。单看标称条件下的图形损失也不够。进入 High-NA EUV 与曲线掩模以后，还要一起报告工艺窗口和最坏情形 EPE。运行时间、显存、写版负担与检验能力，决定这份解能不能离开论文里的 clip。Hamilton-Jacobi 方程解决边界怎样移动。Level Set 能不能继续留在生产流程里，还要看它怎样接上 GPU、AI、Mask3D、MRC、MPC 和原生曲线数据。论文里的新边界由 ϕ 穿过零点产生。生产工具还得把它变成能通过规则检查、掩模写入和晶圆验证的曲线。如果后面几步接不住，前面的优化指标再漂亮，也只是一张仿真结果。参考文献与延伸阅读[1] S.
